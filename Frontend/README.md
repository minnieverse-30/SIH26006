# SAYLVI Frontend

SAYLVI is an AI-powered freight forecasting and vessel chartering decision-support interface built for SIH 2026.

## Frontend stack

- React 19
- Vite
- React Router
- Tailwind CSS
- Recharts
- React Icons

## Run locally

```bash
npm install
npm run dev
```

## Product flow

Dashboard → New Analysis → Freight Forecast → Vessel Match → Vessel Tracking → Cost Comparison → Decision → What-If Analysis → Reports

## Prototype status

The current frontend uses clearly marked prototype data so the interface can be completed before the intelligence backend is connected. Forecasts, vessel positions, costs and recommendations should not be treated as live operational outputs.
